# 포털 챗 PPT — 보낸 결과를 대화에 남기기 · DRM 문서를 PC 의 PowerPoint 로 풀어 올리기 (2026-10-22)

> 요청서 [request.md](request.md)(사양 — A1~A7 · B1~B7) · 체크리스트 [checklist.md](checklist.md) · 결정 [context-notes.md](context-notes.md).
> 대상은 HWAXPortal(백엔드 · 화면 · PC 추출기)과 HWAXAgentServer(이력 · 그림 다시 싣기 문구). AIDataHub · Report Archive 는 고치지 않는다
> (RA 는 이 리포에서 커밋하지 않는다 — 코드는 읽기만 했다). **완료 10-23** — 에이전트 서버 `5033072`(A2 근거 머리 · A3), 포털 `e8aacea`(A4) ·
> `fbe18af`(근거 kind) · `c8896f0`(B1 · B2 · B3 · B7) · `0e9ef5b`(화면 A1 · A2 · A5 · A6) · `252049e`(B4 · B5 · B6). 남은 것 Windows 실시험(6절) ·
> dev 에이전트 서버 재기동(확인 뒤) · cae00 반영.

## 1. 무엇 · 왜

(A) 웹 챗에서 PPT 를 'AI 데이터 허브' · 'Report Archive' 로 보내면 결과가 패널 안에서만 끝났다. 대화에는 아무것도 남지 않아 다음 질문
「방금 변환한 것 검토해 줘」 앞에는 예전에 올린 그림만 실렸고, 모델은 그 그림을 검토했다. Report Archive 로 보낸 초안은 29쪽 모두 블록 0 이었다.

(B) DRM(NASCA) 문서는 서버가 못 읽는다. 지금은 PC 추출기를 손으로 세 걸음(내려받기 · 끌어 놓기 · 다시 붙이기) 돌려야 한다. 웹 챗의
단추 하나로 PC 의 PowerPoint 가 열어 뽑고 포털로 바로 올려 지금 입력창에 붙게 한다.

## 2. 대조로 바뀐 전제(PP-D2 · PP-D6 · PP-D7)

- **RA 0블록의 원인은 포털이다.** RA 가져오기(`/api/imports/pptx`)가 주는 쪽은 저장 꼴(`ReportPage`)이라 위젯 정의(`extra_blocks` — id · type ·
  props)와 내용(`content` — id → 내용)이 따로 있다. 포털은 그것을 그대로 `create_report_draft`(AI 초안 API)에 넘겼고, 그 API 는 정의 항목
  **안의** content 를 읽어 전부 '내용 없음 — 건너뜀' 으로 버렸다. RA 코드를 읽기 전용으로 돌려 확인했다(만든 PPTX — 종전 꼴 쪽마다 0블록,
  고친 꼴은 가져오기와 블록 · 내용 · 정의가 같다).
- **A6 은 결함이 아니다.** 붙인 문서(`attachedDocs`)는 처음(1901dbf)부터 보낸 뒤에도 남았다 — 대화에는 문서 본문을 남기지 않으므로 칩을 떼기
  전까지 매 턴 다시 가는 것이 뒤따르는 질문을 받는 길이다(그림 커밋 2ff8dc0 도 '문서와 달리' 라고 적었다). 주석만 낡았다.
- **A7 은 하지 않는다.** AIDH 의 호출자는 게이트웨이 서비스 키라 최종 사용자를 모른다. '호출자의 최근 inbox 파일' 을 가를 수 없고, 다
  보이면 남의 파일 이름이 샌다. A1 · A2 로 파일 이름이 대화에 남아 필요도 줄었다.

## 4. 하지 않는 것

- A7(AIDH `list_inbox`) — 2절. 필요하면 AIDH 쪽에 신원을 전하는 길부터 정해야 한다.
- 다시 저장(SaveAs)한 PPTX 보내기(B6 선택) — 사용자 결정 10-22. 그래서 PC 로 푼 문서는 Report Archive 로 보낼 수 없다(RA 가져오기는 PPTX 만 받는다).
- 평문 PPTX 의 PC 길 — 평문은 서버가 그림 · 표까지 읽는다(그쪽이 낫다). 단추는 암호 · 모름 판정 안내에만 둔다(PP-D10).
- 서버가 받은 글을 대화에 직접 쓰기(B2 의 '표의 대화에 붙인다') — 브라우저가 받아 문서 칩으로 붙인다. 손으로 하던 길과 같은 끝이고, 사람이 보고 보낸다(PP-D8).
- 다시 싣기를 빼거나 그림이 나온 턴 뒤로 옮기기(A3 ⚠) — 문구 보강만.

## 6. 올린 뒤 할 일

- **cae00** — `./infra/scripts/update-all.sh` 한 번이면 포털(백엔드 · 화면 · 추출기)과 에이전트 서버가 함께 온다. 에이전트 서버는 심의가

- **사람 몫(Windows PC 한 대)** — 이 판의 PC 도우미는 dev 에서 돌려 보지 못했다(PP-D9 ⑦). 다음을 한 번 본다.
  1. 암호 PPT 를 붙여 안내의 '도우미 설치 배치' 를 받아 실행 → `%LOCALAPPDATA%\HWAX\` 에 추출기 · `hwax-doc.json` 이 생기는지.
  2. 'PC 의 PowerPoint 로 열어 가져오기' → 브라우저가 열기를 묻고 → 도우미가 **받는 계정**을 보이고 묻는지 → 파일 고르기 → 문서 칩이 붙는지.
  3. 슬라이드 그림을 켜고 한 번 — DRM 이 내보내기를 막으면 글만 가고 경고가 떠야 한다.
  4. 도우미에서 [아니오] · 파일 고르기 취소 → 화면이 곧바로 '취소했습니다' 로 바뀌는지. 10분 넘겨 누르면 '만료' 인지.
  5. 남이 받은 표의 링크를 누르면 받는 계정이 남으로 보이는지(그때 [아니오]).
  막히면 `%LOCALAPPDATA%\HWAX\hwax-doc.log` 를 보낸다(본문 · 표는 적지 않는다).

## 7. C — 끌어다 놓기(사용자 요청 10-23)

'+' 단추를 쓰지 않는 사람도 그림 · PPT 를 챗에 끌어다 놓아 붙이게 한다(PP-D16).

| # | 무엇 | 어디 |
|---|---|---|
| C1 | 끌어다 놓기는 '+' 단추와 **같은 길**이다 — 그림은 여럿, 그 밖(PPT · Word · PDF · CSV · STEP …)은 한 번에 하나. 함께 놓은 나머지는 이름을 대고 알린다(조용히 빼지 않는다 — '+' 로 여럿 고를 때도 같다) | 화면 `Composer` |
| C2 | 챗 · 심의 화면은 **화면 어디에 놓아도** 입력창에 붙는다 — 끄는 동안 놓을 자리를 화면 전체에 보이고, 브라우저가 파일을 열어 화면을 떠나지 않게 막는다. 떠 있는 챗 창(독)은 **입력창 위에 놓을 때만** — 독은 닫혀도 입력창이 붙어 있어, 화면 전체로 받으면 다른 화면의 끌기를 가로챈다 | `ChatPage` · `DeliberatePage` · `ChatDock` |
| C3 | 답을 받는 중 · 붙일 권한이 없을 때는 놓아도 붙이지 않고 까닭을 말한다('+' 단추가 숨는 때와 같다). 파일이 아닌 끌기(글 · 링크)는 건드리지 않는다 | `Composer` |

## 8. D — 이 대화에서 분석(사용자 요청 10-23)

PPT · Word · PDF · Excel 을 올리면 'Report Archive 로 · AI 데이터 허브로' 둘뿐이었다 — 평문 문서를 **이 챗에서 읽고 묻는** 길이 없었다(암호
문서만 PC 도우미로 그 길이 있었다). '어디로 보낼까요' 에 셋째 목적지를 더한다(PP-D17).

| # | 무엇 | 어디 |
|---|---|---|
| D1 | `chat` 목적지 — AI 데이터 허브의 변환기를 빌려(그 사람 명의 · 허브를 쓸 수 있는 사람만) 글 · 목록 · 표 · 차트 데이터 · 발표자 노트를 `.hwax.md`(손 추출과 같은 꼴 — 슬라이드는 `[s.N]`)로 옮겨 돌려준다. **어디에도 저장하지 않는다** — inbox 사본은 변환 뒤 지운다 | 포털 `upload.DESTINATIONS` · `routes._dispatch_inner` · `upload.record_markdown` |
| D2 | 화면은 그 글을 입력창의 문서 칩으로 붙인다(PC 도우미 · 손 추출과 같은 끝 — 붙인 문서로 할 일 단추가 뜬다). 대화에 '보냈다' 알림은 남기지 않는다(보낸 것이 아니다) | `UploadRouter` · `DocDispatchPanel` · `Composer` |
| D3 | 그림은 아직 글로 옮기지 않는다 — 문서에 '[그림 N] … — 그림 내용은 글로 옮기지 않았다' 로 자리만 남긴다. 그림 판독(VLM)은 7절 다음 단계(cae00 시범 뒤)에 이 길에도 붙인다 | — |
