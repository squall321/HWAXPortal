## 덧붙임 — 토큰 절감 비교 테스트 돌리기(사람 몫 · 비용이 든다)

정본은 포털 `infra/offload-eval/README.md` 1절이다. 같은 과제 16개를 「맡기지 않음(지금)」 과 「서버에 맡김(2판)」 두 갈래로 Claude Code(`claude -p`, Opus 5.5)를
반복 2번씩 돌려 Claude 토큰 · 비용 · 시간 · 도구 호출 수 · 서버 LLM 토큰을 모으고, Sonnet 이 어느 갈래인지 모른 채 두 답을 판정한 뒤 사람이 4쌍을 본다.

- **안전** — 사람 없이 돌므로 Claude Code 가 부를 수 있는 도구는 게이트웨이가 읽기로 확인한 것(`routine_read` — 루틴과 같은 울타리)뿐이다. `invoke_tool` ·
  `rest_call` · 쓰기 도구 · 셸 · 파일 쓰기는 문맥에서 빠진다. 실행마다 대조해 막을 도구가 보이거나 돌면 멈춘다(끝 코드 3).
- **차례**
  1. `node --version`(18 이상) · `claude --version`(Opus 5.5 를 아는 판) · `claude` 를 열어 `/status` 로 로그인 확인(사람).
  2. 6절의 2판 스위치를 켜고 재기동.
  3. `read -rs HWAX_GATEWAY_PAT && export HWAX_GATEWAY_PAT`(토큰 화면의 **일반** PAT — 화면 · 이력에 남지 않게).
  4. `node infra/offload-eval/run-eval.mjs check` — `✓ 돌릴 준비가 됐다` 가 뜰 때까지(돈 안 듦).
  5. 연기 시험 `node infra/offload-eval/run-eval.mjs run --only T4 --reps 1 --out ~/hwax-offload-eval-smoke --max-budget-usd 5` — 두 실행 비용의 합 × 32 가
     본 실행의 어림이다. 어림이 괜찮으면 —
  6. `node infra/offload-eval/run-eval.mjs run --max-budget-usd 5`(64 실행 · 끊기면 같은 명령으로 이어 간다) → `… judge` → `… human`(`human-review.md` 4쌍에
     A · B · 무를 적는다 — `human-key.json` 은 다 적은 뒤에 연다) → `… report`.
  7. 끝나면 `unset HWAX_GATEWAY_PAT`. 2판 스위치를 그대로 둘지는 결과를 보고 정한다.
- **판정 기준(제안 — 손잡이로 바꾼다)** — 「품질 차이 없음 = 판정 패배율 ≤ 10% 이고 숫자 대조 어긋남이 늘지 않음」. 그 위에서 Claude 토큰 · 시간이 얼마나
  줄었는지를 본다(서버 LLM 토큰은 따로 — 위임 몫만 정확하고 작성 · 변환 · 묻기는 호출 수만 센다).
- **돌려받을 것** — `report.md` · `summary.json` · 적은 `human-review.md` · `allowlist.json`. ⚠ 답에 사내 과제 내용이 들어 있다 — 이 리포나 받은 편지함이
  아니라 **사용자에게 직접** 준다. 이 글의 답에는 보고서 요약 줄(두 갈래 토큰 · 시간 중앙값 · 판정 승 · 무 · 패)만 적는다.
- **Q39** 토큰 절감 비교 — 연기 시험의 두 실행 비용 합 · 본 실행을 돌렸는지 · 보고서 요약 줄(위) · 사람 표본 4쌍의 판정과 판정 모델의 일치 수.
