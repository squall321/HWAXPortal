## Q1 — MaterialTwin 자연 키(HH-10)

- **까닭** — MaterialTwinWeb 세션이 HH-10 을 보려 했는데 그 id 들이 dev DB 에 없다. id 는 박스마다 따로 매긴다. 같은 행을 dev 에서 찾으려면 자연 키가 필요하다 —
  출처는 제목 · DOI · URL · 로컬 경로, 값은 재료 이름 · 물성 키 · 값 · 단위 · 조건.
- **명령(읽기 전용으로 연다)** —

  ```bash
  DB=~/Projects/HEAXHub/var/app_data/materialtwin_web/materialtwin.db    # 없으면 ls ~/Projects/HEAXHub/var/app_data/materialtwin_web/
  python3 - "$DB" <<'PY'
  import sqlite3, sys
  db = sqlite3.connect(f"file:{sys.argv[1]}?mode=ro", uri=True)
  q1 = "SELECT id, kind, title, doi, url, local_path FROM source WHERE id IN (1534, 3184) ORDER BY id"
  q2 = ("SELECT v.id, v.material_id, m.name, v.property_key, v.value_num, v.value_text, v.unit, v.conditions, v.source_id "
        "FROM property_value v JOIN material m ON m.id = v.material_id WHERE v.id BETWEEN 67907 AND 67910 ORDER BY v.id")
  for q in (q1, q2):
      rows = db.execute(q).fetchall()
      print(len(rows), "행")
      for r in rows:
          print(r)
  PY
  ```

- **기대** — 출처 2행 · 값 4행(모두 `material_id` 254). 행이 모자라면 그 id 가 이 박스에도 없다는 뜻이다 — '없음' 이라 적는다(파일을 못 열었으면 '못 봄').
- **돌려받을 것** — 두 결과 그대로. 사용자가 MaterialTwinWeb 세션에 옮긴다(로컬 경로가 들어 있으니 리포에는 적지 않는다).

- **까닭** — SceneForge 가 Blender Cycles CPU 렌더 잡을 stcx(356대 — 전각도 · 단일 낙하가 도는 클러스터)에 낼 파티션을 고른다. dev 박스는 stcx 를 볼 수 없다.


  못 보면 '못 봄' 이다.
- **돌려받을 것** — 위 출력 그대로 · 센 기간 · (볼 수 있으면) 프롬프트 토큰 분포.

## Q14 — 허브 가족 늘 접두(E-2 · Q-2)로 바뀐 도구 이름

- **까닭** — 10-29 4차 E-2 가 허브 가족(정본 + 형제)의 도구를 늘 `<키>_<이름>` 으로 낸다(포털 `docs/request-1029/design-e2-e4.md` Q-2 a, 사용자 결정 ·
  확인 10-31). 이 박스는 허브 셋이 같은 도구를 내 이미 셋 다 접두라 바뀌는 이름이 0 이어야 한다(M-2). 0 이 아니면 그 옛 맨 이름은 목록에서 빠지고
  호출 별칭으로만 닿는다 — 그 이름에 묶인 운영자 정의 · 허용 규칙이 있는지 dev 가 본다.
- **언제** — update-all 이 게이트웨이 `5f4ba5f` 이후 판을 받아 게이트웨이가 다시 뜬 뒤.
- **명령(읽기)** —

  ```bash
  curl -s --noproxy '*' 127.0.0.1:9110/health | python3 -c 'import json,sys
  r = json.load(sys.stdin)["core_vocab"]["roles"]
  print("family", r["family"])
  print("noncore", r["noncore"])
  print("sibling_taglines", r["sibling_taglines"])
  print("family_prefixed", r["family_prefixed"]["count"], r["family_prefixed"]["names"])'
  ```

- **기대** — `family` 의 키가 모두 `True` · `family_prefixed` 0. `False` 인 키 · 0 이 아닌 수의 뜻과 고치는 길은 포털 `docs/request-1029/server-setup.md` 8.2 절이다.
- **돌려받을 것** — 네 줄 그대로(도구 이름 · 앱 키만 나온다).
