## Q11. stcx 노드 관리자 · 챗 LLM 운영(사용자를 거쳐)

1. LLM 잡이 GPU 를 gres 로 청하나, 노드의 둘 중 몇 장을 쓰나, cgroup 장치 제한이 있나.
2. GPU 를 읽는 길 가운데 무엇이 되나 — (가) 다음 rolling 때 LLM sbatch 에 nvidia-smi 표본 한 줄(새 잡 없음 — 권장) (나) 1분마다 `srun --overlap` (다) 노드 ssh (라) 이미 있는 내보내기.
3. cae00 에서 1분마다 `squeue` 를 물어도 되나.
4. 같은 노드의 다른 GPU 프로세스를 화면에 보여도 되나, 수만 되나.

## Q12. GLM 운영 팀(사용자를 거쳐)

## Q13. 개인 Claude 의 도구별 결과 크기(토큰 절감 측정)

```bash
python3 - /data/svc/mcp-gateway/audit.jsonl <<'PY'
import json, sys, collections
calls = collections.Counter(); chars = collections.Counter()
for line in open(sys.argv[1], encoding='utf-8'):
    try: r = json.loads(line)
    except Exception: continue
    if r.get('via') != 'pat': continue
    t = r.get('tool') or '-'; calls[t] += 1; chars[t] += int(r.get('chars') or 0)
tot = sum(chars.values()) or 1
for t, n in chars.most_common(20): print(f"{t}\t{calls[t]}\t{n}\t{n*100//tot}%")
poll = sum(calls[t] for t in calls if t.endswith(('_status', 'status')))
print('상태 묻기 호출 비율', poll * 100 // (sum(calls.values()) or 1), '%')
PY
```
