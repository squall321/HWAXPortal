## 1. nginx 평문 막기가 기본 켬(HP-75)

- **기본이 바뀜 — http 8088 로 등록한 MCP 주소는 https 로.** TLS 를 켠 박스에서 conf 를 다시 만들면(update-all · start.sh) 이름이 `-mcp` 로 끝나는 라우트는
  평문 서버(8088)에서 루프백만 받는다 — 사내망 주소의 `http://…:8088/<id>-mcp/mcp` 는 403, https 는 그대로다. 이 박스 안에서 루프백으로 부르는 길은 그대로다.
- 확인 — conf 생성 줄 '평문 서버(:8088)에서 루프백만 받는 라우트 N개 — … 기본'.
- 다른 박스 · PC 가 8088 로 부르는 `*-mcp` 가 있어 당장 못 바꾸면 `infra/.env` 에 `NGINX_TLS_ONLY_ROUTES=none` → `./infra/scripts/gen-nginx-conf.sh` → nginx
  재기동(사람).
- 경로별 업스트림 Host(HP-72)는 박스마다 목록이 달라 기본 끔 그대로다 — 박스 중계를 걷는 권장 차례는 server-setup 2절 1.

## 2. §1b 가 그날 일일 덤프를 롤백 지점으로 다시 쓴다(SE-2 ③ · SYNCEFF-4)

- 그날(박스 시각) 03:30 일일 AIDataHub 덤프가 온전하고(sha256 짝이 맞고) 받을 AIDataHub 판에 alembic 이관이 없으면, §1b 가 새 `-pre` 를 뜨지 않고 그 덤프를
  배포 전 롤백 지점으로 적는다 — '✓ AIDataHub 배포 전 롤백 지점 — 일일 덤프 재사용 — <파일> · <시각>'(끝 요약에도), 기록은
  `${BACKUP_ROOT:-/data/backups}/hwax/<박스>/aidh/predeploy-rollback.log`. 그 실행은 §1b 의 AIDataHub 덤프(27 ~ 28분 · 11 GB)가 없다.
- 이관이 있거나 일일 덤프가 없 · 낡 · 깨졌거나 받을 판을 볼 수 없으면 지금처럼 새로 뜬다('· … 새로 뜬다 — <까닭>', 깨진 덤프는 ⚠).
- 늘 새로 뜨려면 `infra/.env` 에 `HWAX_PREDEPLOY_DUMP=fresh`(○ 줄이 남는다).

## 3. PC 킷 연결 설정에 결과 손잡이 머리가 기본(P-1)
