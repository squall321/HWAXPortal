## Q1 — 리스크 앱 원장의 원문 보존량 · 실제 모델 크기

- **까닭** — 리스크 심사의 결과 원문 보존(영구 · 인용된 것만 · 항목 상한)과 모델 상한(리프 1,500 · 계면 6,000)을 실제 크기를 보고 정하기로 했다
  (10-17 FU-D3). dev 원장에는 실제 과제가 없다. 계면 상한 6,000 이 REST 한 번의 상한 5,000 보다 커서 그 사이 모델이 잘리는 것도 같이 본다.
- **명령(읽기 전용으로 연다 — SQLite `mode=ro`)** —

  ```bash
  DB=~/Projects/HEAXHub/var/app_data/hwax_risk/risk_review.db
  ls -l "$DB"*
  python3 - "$DB" <<'PY'
  import json, sqlite3, sys, time
  db = sqlite3.connect(f"file:{sys.argv[1]}?mode=ro", uri=True, timeout=5)
  since = int(time.time()) - 30 * 86400
  for table, col in (("rr_panel_calls", "started_at"), ("rr_review_calls", "started_at"), ("rr_brief_calls", "fetched_at")):
      try:
          n, b = db.execute(f"SELECT COUNT(*), COALESCE(SUM(LENGTH(result_gz)), 0) FROM {table}").fetchone()
          n30, b30 = db.execute(f"SELECT COUNT(*), COALESCE(SUM(LENGTH(result_gz)), 0) FROM {table} WHERE {col} >= ?", (since,)).fetchone()
          print(table, "행", n, "원문 바이트", b, "· 최근 30일 행", n30, "바이트", b30)
      except sqlite3.Error as e:
          print(table, "못 읽음", e)
  leaf, iface = [], []
  for (ir,) in db.execute("SELECT ir_json FROM rr_snapshots"):
      for s in json.loads(ir).get("sources") or []:
          if s.get("kind") == "mcad":
              st = s.get("stats") or {}
              leaf.append(int(st.get("leaf_instances") or 0))
              iface.append(int(st.get("interfaces") or 0))
  def top(v):
      v = sorted(v)
      return {"n": len(v), "max": v[-1] if v else None, "p95": v[min(len(v) - 1, int(0.95 * len(v)))] if v else None}
  print("mcad 리프", top(leaf))
  print("mcad 계면", top(iface))
  PY
  ```

- **기대** — 표 셋의 줄 셋과 mcad 줄 둘. 스냅샷이 없으면 `n 0` 이다(그때는 '없음'). 파일을 못 열었으면 '못 봄' 과 까닭.
