## Q1. 첫 실행 — 조각 전부

까닭 — 첫 실행은 '병합함' 표식이 없어 조각 전부를 받는다(dev 가 낸 조각 전체). 전체 덤프 길(받기 · 스테이징 색인 · 전체 스냅숏 — 한 시간 남짓)보다
짧아야 맞다. 길이와 크기를 보고 dev 의 조각 수(64)와 보관을 정한다.

update-all 출력의 `3) AIDataHub 데이터(에이전트·레코드) 동기화` 머리 아래 줄을 그대로 옮긴다 — 특히 아래 꼴의 줄.

```text
  받음 N 파일 · 크기 · 초
✓ 조각 계획 — manifest-…
→ staging 에 조각 N개를 실었다
→ 덮을 줄의 앞 모습: /data/backups/aidh/pre-parts-<시각> …
✓ merge 완료(조각 길) …
  ✓ AIDH 조각 merge(바뀐 조각만 — …)
```

- `⚠ AIDH 조각 merge 실패(rc N)` 이면 그 아래 전체 덤프 길이 돌았는지(`✓ AIDH 데이터 merge(…)` 또는 `덤프 변화 없음`)와 `tail -20 /tmp/aidh-merge.log`.
- `○ AIDH 조각 동기화 — Drive 에 조각 목록이 없다` 면 `rclone lsf <리모트>:AIDataHub/db-parts/ | tail -3`(리모트는 `AIDH_DRIVE_REMOTE` 의 앞부분).
- `⚠ AIDH 조각 목록이 전체 덤프보다 하루 넘게 낡았다` 면 그 위의 `[WARN] 조각 목록(…)이 전체 덤프(…)보다 N시간 낡았다` 줄 그대로 — dev 의 하루 한 번 내기가
  멈춘 것이다(병합은 전체 덤프 길로 됐다).

## Q4. StepForge a81 — 도구 수 · 지도 뷰어

까닭 — a81(`dist-20261105-045500Z`)은 상호작용 SVG(`format="svg_live"`)와 과제마다의 지도 HTML 뷰어(`GET /view/{project_id}/atlas`)를 더했다. 도구 수는 그대로(184)여야
하고, 뷰어는 새 반입의 `section_atlas(viewer=true)` 가 짓는다. 그쪽 세션이 청한 확인이다.

```bash
curl -s http://127.0.0.1:9110/tools-map | python3 -c '
import json, sys
d = json.load(sys.stdin); m = d["map"]
print("step_forge 도구", sum(1 for n, a in m.items() if a in ("step_forge", "step-forge", "stepforge")))'
```

- 도구 수가 184 가 아니면 받은 판이 a81 인지 먼저 본다(허브의 앱 판).
- 뷰어 — 개인 Claude(또는 챗)에서 새로 반입한 과제 하나로 `section_atlas(project_id=…, viewer=true)` 를 부르고 답의 `viewer.route` · `public_url` 이 있는지 적는다.
  그 주소를 포털 정문으로 열어(`/apps/step_forge/view/{id}/atlas` 꼴) HTTP 코드와 화면이 뜨는지 적는다. 과제 이름 · id 는 적지 않는다('새 반입 하나').

## Q5. 포털 챗의 SVG 호버

까닭 — 포털 챗이 같은 출처 SVG 그림을 격리 iframe 으로 그리게 됐다(포털 `2ff8d56d` — 화면은 Drive 이미지 판으로 받는다). StepForge 단면 그림을 svg_live 로
받으면 파트 위에 이름 · 경로 풍선이 떠야 한다.

- 챗에서 「단면을 svg_live 로 그려 줘」 꼴로 단면 그림 하나를 받아 파트 위에 마우스를 올린다 — 풍선이 뜨는지 · 그림 오른쪽 위 돋보기로 확대가 열리는지.
- 안 뜨면 브라우저 이름 · 판(`:has()` — Chromium 105+ · Firefox 121+ · Safari 15.4+)과 그림이 iframe 인지(오른쪽 단추 → 검사)를 적는다.

## Q6. 챗의 뷰어 카드 · MCP Apps 패널

까닭 — 포털이 다른 플랫폼의 화면을 챗 안에 띄우게 됐다(`docs/chat-embeds` — 포털 `d9e498cd` · `fb3da32d`, 에이전트 서버 `af17496`, 화면은 이미지 판
`images-20261105-092549Z`). 도구가 준 같은 출처 뷰어 주소는 답 아래 카드(격리 창)로, 앱이 `ui://` 화면을 낸 도구는 패널로 뜬다(패널 호스트 기본 켬).

- 뷰어 카드 — 챗에서 단면 지도가 다 지어진 과제 하나로 「단면 지도 뷰어 열어 줘」(section_atlas · viewer=true) — 답 아래 'step_forge' 카드가 연 채로 뜨는지 · 새로고침
  뒤 접힌 카드로 남는지 · 카드의 '새 탭' 이 열리는지. 안 뜨면 그 답 도구 줄의 결과에 `public_url` 이 있는지(StepForge 쪽 `STEPFORGE_PUBLIC_BASE` 가 비면 null 이라 카드가
  없다)를 적는다.
- 패널 — 이 박스에 `ui://` 화면을 내는 앱(SimFlow 의 `open_*_panel` 등)이 있으면 그 도구를 부르게 해 패널이 뜨는지. 없으면 '해당 앱 없음'.
- 끄고 싶으면 박스 `backend/.env` 에 `MCP_APPS_HOST=0` 뒤 포털 재기동(사람 몫 — 끄기 전에 받은 편지함으로 까닭을 알린다).
