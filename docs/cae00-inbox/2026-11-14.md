## Q1. SignalForge 비밀번호 · 듣는 주소 확인(읽기만, SignalForge 세션 부탁)

dev 에서 SignalForge 의 Postgres · Redis 비밀번호가 공개 리포 `.env.example` 기본값과 같고 모든 인터페이스에서 열려 있어 11-14 에 막았다
(비밀번호 교체 · 루프백만 듣기 · `.env` 600). cae00 도 같은지 **읽기만** 해 본다 — 값은 찍지 않는다. **지금 바꾸지는 않는다**(바꾸는 절차는 SignalForge 가 동결이 풀린 뒤 낸다).

```bash
cd ~/Projects/SignalForge
for k in POSTGRES_PASSWORD REDIS_PASSWORD; do a=$(grep -m1 "^$k=" .env | cut -d= -f2- | sha256sum); b=$(grep -m1 "^$k=" .env.example | cut -d= -f2- | sha256sum); echo "$k 기본값과 $([ "$a" = "$b" ] && echo 같다 || echo 다르다)"; done
ss -ltn | awk '$4 ~ /:(5434|6379|26379|18000)$/ {print $4}'
ls -l .env | awk '{print $1}'
```
