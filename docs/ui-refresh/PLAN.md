# 포털 UI 개선 계획 — '세련되지 못하다' 는 비평의 원인과 고치는 순서

> 2026-10-02 리뷰. 임시 포털(mock 로그인·임시 저장소)을 띄워 11개 화면을 1440·1280·1024·768·390 폭으로 캡처하고, 다섯 관점
> (시각 체계·레이아웃과 정보 구조·챗 화면·반응형과 접근성·스타일 코드 구조)과 누락 점검 1회로 검토했다. 높은 심각도 주장 다섯은
> 화면·코드로 다시 확인했다. 리뷰는 대부분 **관리자 계정 · Linux 글꼴**로 본 것이다 — 기본 권한 사용자 화면과 Windows 글꼴은
> 단계 0 의 캡처 세트로 다시 본다(context-notes D-7).

## 1. 결론 — 원인은 넷이다

**① 군데군데 '깨져 보인다'.** 평범해 보이는 것과 깨져 보이는 것은 다르다. 사용자가 가장 먼저 닿는 자리에 깨진 것이 몰려 있다.

| 무엇 | 어디서 보이나 | 원인 |
|---|---|---|
| 업데이트 팝업 제목에 `**자동 로그인**` 이 그대로 | 로그인 직후 **모든 사용자** | 제목만 `<Bold>` 를 안 거친다(ChangelogPopup·ChangelogPage) |
| 파일을 붙이면 **흰 상자에 흰 글씨** 패널(대비 1.15:1) | 챗 첨부 흐름 전체(5개 패널) | 정의 안 된 CSS 변수가 라이트 테마 값으로 떨어진다(`var(--surface-2,#f6f7f9)` 등 9개) |
| 심의 첫 화면 제목이 잘려 스크롤로도 안 보임 | /deliberate (1280·1440 모두) | `align-items:center` + `overflow:auto` — 넘치면 위가 잘린다 |
| 앱 타일 11개 중 5개가 **자리표시 동그라미** 아이콘 | /apps | PlatformLogo 기본 분기 |
| 입력창 `+` 가 브라우저 기본 회색 버튼 | 챗·심의·독 — 가장 많이 보는 컨트롤 | 전역 `button` 에 배경 지정 없음 |
| 내보내기 버튼 4개가 첫 질문 말풍선을 덮음 | 대화 화면 | 절대배치 |
| **헤더 메뉴가 '심/의', 'Sign/out' 으로 쪼개짐** | **1280px(1920 모니터 150% 배율 — 사내 노트북 흔한 설정)**, 관리자는 1340px 미만, 일반 사용자는 1060px 미만 | 헤더 전부 인라인 스타일 · 줄바꿈 금지·반응형 없음 |
| 390·768px 에서 모든 화면이 929px 로 가로 넘침 | 모바일·태블릿 | 같은 헤더 |
| 운영자용 '배선 설정 5건 · 필수 3' 노란 상자가 **일반 사용자에게** 앱 목록보다 먼저 | /apps | 역할 확인 없음(프론트·백엔드 둘 다), manual 항목은 영원히 안 사라짐 |
| SSO 실패가 흰 바탕 JSON 원문 | 로그인 실패 | ACS 오류를 화면으로 안 돌린다 |

**② 디자인 체계가 없다.** 색 토큰이 6개뿐인데 코드에는 고유 색 hex 125개·rgba 99개·글자 크기 59가지·모서리 23가지가 있고,
11개 화면의 버튼이 계산값 기준 **29가지 모양**이다. 강조색이 셋으로 갈린다 — 삼성 블루 `#1428a0`(흰 글자), 라벤더 `#98a8ff`(검은 글자),
`#2563eb` 폴백. 그중 `#1428a0` 을 **글자·링크 색**으로도 써서 어두운 배경 대비가 1.66:1 이다('가입 신청', 404 '돌아가기' 가 안 보인다).
인라인 `style={{}}` 404곳(절차 133, 토큰 44 …)이 화면마다 다른 말투를 만든다. 결과적으로 챗(가장 다듬어짐)·앱 허브(그라디언트 카드)·
관리/유틸 화면(인라인·기본 폼 컨트롤) 세 가지 '방언' 이 한 앱에 있다.

**③ 한국어 타이포가 손대지지 않았다.** 한글 글꼴 지정 없음(system-ui → Windows 는 맑은 고딕), 줄 간격 기본값, `word-break: keep-all`
없음 → '홍/길/동', '로/그/인', '연/결/됨' 처럼 음절 단위로 줄이 바뀌고 '토큰 발급' 버튼이 세로로 선다. 맑은 고딕이 못 그리는 굵기
(560·620·650)를 요구하고, 안내 문장 일부는 고정폭 글꼴이라 터미널 출력처럼 보인다.

**④ 뼈대(정보 구조)가 흩어져 있다.** 헤더에 메뉴 10개 + 도메인 글자 + 영어 'Sign out' 이 한 줄이고 관리자 메뉴가 섞여 있다. 페이지마다
본문 폭이 7가지, 제목 스타일이 3가지라 메뉴를 누를 때마다 제목이 120~384px 사이에서 옆으로 튄다. 첫 로그인에는 59건 업데이트
모달이 뜨고, 토큰 화면은 성격이 다른 다섯 가지를 한 줄로 쌓아 정작 '내 토큰' 이 맨 아래에 묻혀 있다. 같은 화면을 메뉴는 'API 토큰',
제목은 'AI 토큰 (PAT)', 권한 표는 'API 토큰 · MCP 개인 연결' 로 부른다.

## 2. 지킬 것 — 개편 중 건드리지 않는다

- **챗 답변 렌더** — 표(헤더 구분선·가로 스크롤 격리)·코드블록(언어·줄바꿈·복사)·콜아웃·KaTeX. ChatGPT·Claude.ai 수준에 가깝다.
- **컴포저 동작** — 한글 IME 조합 중 Enter 무시, 자동 높이, 스트리밍 중 중지 전환. 스트리밍·오류 상태(원인·다음 행동·다시 시도로
  바꾸는 friendlyError), 위로 스크롤하면 자동 스크롤 멈춤, reduced-motion 대응.
- **심의 회의록** — 페르소나 색·이니셜, 입장 배지, 라운드 구분선, 의사결정문 카드. 전문가 조직도 3단 브라우저.
- **원칙** — 챗을 첫 화면으로, 권한 없는 메뉴는 비활성 대신 숨김, 기본 다크 팔레트(--fg 15.4:1·--muted 7.2:1), icons.tsx 선 아이콘 체계,
  PlatformLogo 의 기존 글리프 6개, 클래스 접두사(cx-·pv-·upl-)로 충돌이 거의 없는 CSS.

## 3. 결정 — 리뷰 관점끼리 갈린 것(근거는 context-notes)

| 쟁점 | 결정 |
|---|---|
| 강조색 | 글자·링크·선택·포커스는 `#98a8ff`(배경 8.4:1), 주 버튼 채움은 `#3b5bdb` + 흰 글자(5.7:1, 버튼-배경 3.3:1). `#1428a0` 은 로고·브랜드 마크 전용. 라벤더 채움 버튼과 `#2563eb` 폴백은 없앤다 |
| 대화상자 | 네이티브 `<dialog>.showModal()` 하나로 — 의존성 없이 포커스 가둠·Esc·복귀·top layer. 7개 대화상자를 옮긴다 |
| 앱 타일 색 | 카드 중립 + 단색 글리프. 분류는 한국어 4묶음(해석·시뮬레이션 / 데이터·지식 / AI 플랫폼 / 설계 자동화) |
| 폭 우선순위 | **960~1536px**(사내 노트북·반화면)이 먼저. 390px 투자는 접속 원장 UA 비율을 보고 정한다 |
| 글꼴 | 한국어 UI 글꼴을 **번들**(빌드 산출물에 포함 — cae00 은 런타임 CDN 불가). Pretendard(OFL) 기본, 사내 라이선스 글꼴이 있으면 그것 — **사용자 결정** |
| 라이트 테마 | 이번 범위 밖(다크 전용 유지). 뒤집혀 있는 prefers-color-scheme 규칙 하나는 지운다 |

## 4. 단계

각 단계는 독립 커밋 묶음이고 따로 되돌릴 수 있다. 화면을 고치면 `pnpm build` → `build-all-to-drive.sh portal` 이 따라온다.

### 단계 0 — 안전망 (≈1일) — **이것부터**
프론트에 시험이 하나도 없다. 404곳의 인라인 스타일과 전역 CSS 를 고치는 일은 지금 눈감고 하는 것과 같다.
- Playwright 시각 회귀: 임시 포털 레시피(mock 로그인·임시 저장소·SERVE_FRONTEND) + 시드 대화. 12개 경로 × {1440, 1280, 1024, 768, 390} ×
  {관리자, CAEG, 기본 권한} + 상태(업데이트 팝업, 파일 첨부 패널, 전문가 선택기, 심의 회의록, 로그인 오류). 기준선은 지금 화면.
- 픽셀 외 단언 셋 — ① 모든 경로 `scrollWidth ≤ 화면 폭`(가로 넘침) ② 200×40 넘는 요소에 밝은 배경(휘도 > 0.8) 없음(흰 패널 계열)
  ③ `var(--x)` 가 전부 :root 에 정의됨(스크립트, 빌드 실패로).

### 단계 1 — '깨져 보이는 것' 제거 (1~2일, 전부 S)
1. 업데이트·절차·전문가 설명의 `**` — 제목에 `<Bold>`, 그리고 `InlineMd`(굵게·코드만)로 공용화
2. 미정의 변수 9개를 다크 값으로 정의하고 라이트 폴백 리터럴(`#fff`·`#f6f7f9`·`#111`)을 걷어 낸다
3. 심의·챗 히어로 상단 잘림 — `align-items: safe center`(또는 `margin-block:auto`), 땜질 두 줄 삭제
4. 전역 `button { background: transparent }`, `+` 를 고스트 아이콘 버튼으로
5. 헤더 응급 처치 — 링크 `nowrap`·`flex:none`, 도메인 글자 삭제, nav 가로 스크롤(본 재구성은 단계 2)
6. `body { word-break: keep-all; overflow-wrap: anywhere; line-height: 1.6 }`, 한국어 문장의 고정폭 글꼴 제거
7. 링크·오류 대비 — `a { color: #98a8ff }`, `--danger: #f28b82`, 전역 `:focus-visible` 링
8. 기본 동그라미 아이콘 5종을 같은 결의 글리프로(SignalForge·Smart Twin Explorer·Risk Review·AI Ready·ECAD)
9. 배선 설정 상자 — 관리자 전용(프론트·백엔드), manual 항목 '확인함', 위치는 관리 영역
10. 업데이트 팝업 — 처음 온 사람에게는 띄우지 않고 '본 날짜' 만 기록, 이후에도 제목 목록 최대 5줄
11. 한국어 통일 — 로그아웃 · 삼성 AD 로그인(SSO) · 404 · 로그인 오류 문구 · 앱 분류 칩
12. SSO 실패를 `/login?error=` 로 돌려 한국어 안내 + 다시 로그인 버튼
13. 파비콘, 라우트별 탭 제목('챗 · HWAX'), 닫힌 챗 독에 `inert`(보이지 않는 Tab 정지점 5개 제거)

### 단계 2 — 기반 (≈1주)
- `tokens.css` — 표면 3단·테두리 2단·글자 3단, 강조(채움·글자·soft), 상태색(danger·warn·ok·info 각 fg/bg/border), 글자 크기 8단(12px 하한),
  간격 4px 단위, 모서리 6/8/12/16/pill, 그림자 3단, z 단계. **옛 이름은 별칭으로 남겨** 기존 4.8천 줄 CSS 가 그대로 돈다.
- 한국어 글꼴 번들, 굵기 400/500/600/700 만.
- 폼 컨트롤 전역 기본값(높이 36px·테두리·포커스) — 관리 화면의 기본 회색 입력칸이 한 번에 정리된다.
- 헤더 3구역 — `[HWAX] 챗 · 심의 · 앱 · 절차 …… [관리 ▾ (n)] [홍길동 ▾]`. 관리 ▾ = 사용자 관리·접속 이력·배선 설정(관리자만),
  계정 ▾ = 내 권한·개인 토큰·연결·업데이트 이력(새 소식 점)·로그아웃. '리스크 심사' 는 메뉴에서 빼고 앱 타일로(/risk 딥링크 유지).
  1100px 미만 이메일 숨김, 900px 미만 햄버거 시트.
- 레이아웃 라우트 하나로 셸을 한 번만 마운트하고 폭은 두 등급(--w-read 880px · --w-wide 1200px, 챗·심의는 전체 폭).
  공통 `PageHeader`·`PageState`(로딩·오류·빈 상태 — friendlyError 공용화)·`EmptyState`. 404 를 셸 안으로.
- 용어집 — 챗 / 심의 / 앱 / 절차 / 내 권한 / 개인 토큰 / 업데이트 이력 / 관리. 메뉴 라벨 = 페이지 제목.

### 단계 3 — 원형 컴포넌트와 이행 (1~2주)
- `src/components/ui/` — Button(주·보조·고스트·위험·링크, sm/md), Field(Input·Select·Textarea + 라벨·도움말·오류), Card, Badge(톤 5),
  Banner, Table(촘촘·보통, 숫자 열), Tabs, Modal(네이티브 dialog), Menu. 스타일은 `ui.css` 한 파일, 토큰만 쓴다.
- 대화상자 7개를 Modal 로, 이모지 UI 아이콘 69곳을 icons.tsx 선 아이콘으로(이모지는 사용자·LLM 본문에만).
- 인라인 스타일 이행 — 관리 화면 → 토큰 → 절차(133) 순. 디렉터리 단위로 ESLint `style={{…}}` 금지와 hex 리터럴 래칫을 켠다.

### 단계 4 — 화면별 재설계 (1~2주)
- **챗 컴포저 v2** — 검색·Thinking 을 입력창 안 도구줄의 작은 토글 알약으로(전폭 막대 두 줄 제거), 전문가 칩, 심의 옵션 popover.
  스레드 헤더 행(제목 · 심의로 넘기기 · 내보내기 ▾ · 활동). 빈 상태는 칩 더미 대신 2×2 시작 카드. 우측 레일은 활동이 있을 때만.
  글 블록 최대 46rem(표·그림은 넓게), 숫자 열 tabular-nums.
- **심의** — 회의록 화자를 기계 키(`pcb-warpage`) 대신 사람 이름으로, 저장된 심의의 진행 표시 완료 처리, 카드의 내부 ID 를 툴팁으로,
  '얹을 층' 을 심의 옵션 안으로, 전문가 선택기 관련도 3단계(1등이 늘 100% 인 표시 제거)·진단 문구 접기.
- **/apps** — 히어로를 120px 이하 헤더(제목·한 줄 설명·검색)로, 한국어 4묶음, 설명 3줄·태그라인 1줄 클램프, 열기 동작 통일(새 탭 + ↗).
- **로그인** — SSO 를 맨 위 주 버튼으로, 로컬 폼은 접이식(서버가 로컬 로그인을 끄면 숨김), 로고 카드.
- **토큰** — 탭 셋(개인 토큰 / 허브에 보일 앱 / 외부 연결), 빈 상태에 다음 행동.
- **내 권한** — 맨 위에 단일 행동('소속 요청 — 이것으로 N개가 열립니다'), '쓸 수 있음' 은 요약 한 줄, 플랫폼 줄에 설명.
- 업데이트 '본 날짜' 를 서버 원장에(새 PC·캐시 삭제 뒤 59건 팝업 재발 방지).
