## 3. 지키는 것

- **Report Archive 는 읽기만.** 받기는 `git merge --ff-only origin/main` 하나다. 커밋 · 푸시 · 그 리포 파일 고침은 하지 않는다. 어긋남은 우리 쪽 코드를 고친다.
- **끝난 것부터 올린다.** 항목 하나가 끝나면 시험 → 병합(`--no-ff`) → 올림까지 하고 다음으로 간다. 여러 리포에 걸치면 받는 쪽이 먼저 나간다.
- **기본값에서 동작이 바뀌지 않게.** 새 길은 스위치 기본 끔 또는 인자가 있을 때만. 리스크 심사에는 새 길을 열지 않는다(D-18).
- **운영 박스에서만 되는 것은 dev 에서 흉내 내지 않는다.** 한 줄 명령 · 절차서 · 받은 편지함까지가 dev 몫이다(측정 · 튜닝의 고리는 cae00 에서 닫는다).
- **모델로 품질을 재는 일은 모델 · 횟수를 먼저 묻는다.** 돌아가는지만 보는 시험 심의는 가장 작은 판으로.
- **다른 세션이 짓는 중인 가지는 건드리지 않는다.** 그 세션의 문서는 근거가 분명한 줄만 맞춘다.
- **재기동은 무엇이 켜지는지 적고 한다.** 떠 있는 판과 HEAD 사이의 다른 세션 커밋도 같이 켜진다.
