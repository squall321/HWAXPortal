# HWAX Agent Server 기능·마일스톤 요약 (비개발자용)

> **HWAX Agent Server** = HWAX 포털 MCP 채팅의 "두뇌". 실제 AI 모델 호출과 업무 도구 실행을 담당하는 별도 서버.
> 포털은 얇은 통로(인증·중계)일 뿐, 진짜 일은 여기서 처리.

작성 기준: HWAX 포털 통합 대상 시스템 정리 (비개발자용 개조식) — 2026-08-28 갱신

---

## 주요 기능 7

### 1. AI 두뇌 연결
- 실제 답을 만드는 AI 모델에 접속
- 개발용(작은 두뇌)·운영용(큰 두뇌) 전환은 주소 한 줄 교체
- 운영망은 Report Archive 의 LLM 설정을 상속(env-kit `@FROM_RA:` 마커)해 상암 GLM 을 자동 연결
- 모델 교체에 코드 수정 불필요

### 2. 에이전트 진행
- 단순 응답이 아니라 "도구가 필요한지" 스스로 판단
- 도구 실행 후 그 결과를 근거로 답변
- "지어내지 말 것" 지침 내장

### 3. 업무 도구 연동
- 외부 업무 프로그램을 AI 에 장착
- MCP 게이트웨이가 여러 백엔드의 도구를 단일 관문으로 집계 — 현재 **255종**(보고서·VOC·재료·해석·심의 등)
- 도구 추가는 설정만으로 가능

### 4. 설정·보안 관리
- 연결 도구 목록·접속 열쇠를 코드와 분리 보관
- 비밀정보·내부 주소를 코드/매니페스트에 **하드코딩 0** — 주입된 주소에서 프록시 예외(NO_PROXY)를 자동 도출
- 비밀정보 외부 노출 차단, 환경별 설정 분리

### 5. 실시간 응답
- 답을 글자가 흐르듯 즉시 출력
- "분석 중"·"도구 사용 중" 진행 상황 표시
- 포털 화면 규격에 맞춰 전달

### 6. 무중단·안전
- 도구 고장 시에도 가능한 선에서 답변
- 오류 시 사용자엔 안전한 메시지만 노출
- 내부 정보 차단

### 7. 다중 전문가 심의 (협업진단)
- 여러 도메인 전문가 페르소나가 **도구 근거 위에서 여러 라운드로** 의견을 수렴해 의사결정문 생성
- 시뮬레이션 심의는 2단에 **수치 스파인 7석을 고정 착석**, 발언이 지식카드를 인용(**카드 그라운딩**, 근거는 AIData Hub)
- 3단 **'구축 계획서'(build-plan)** 로 특화 파라메트릭 시뮬 모듈 개발계획까지(opt-in)
- 챗·심의에서 전문가/도구를 직접 지정 가능(pinned)

## 개발 마일스톤 6단계

### M1. 골격
- AI 답을 그대로 화면에 전달
- 기초 챗봇 단계 (도구 없음)

### M2. 에이전트화 ★분기점
- 도구를 직접 쓰는 비서로 전환
- 도구 실제 사용까지 검증 완료

### M3. 하드닝
- 오류 시 내부 정보 감춤
- 보안·신뢰 안전장치

### M4. 실전 툴 투입
- 연습용 도구 → 실제 업무 도구(보고서·VOC)
- 데모 졸업, 제품 단계 진입

### M5. 라이브
- 게이트웨이로 도구 정상 가동(현재 255종 집계)
- 운영 전환은 Report Archive LLM 상속(주소 주입)으로 연결

### M6. 다중 전문가 심의 (현재)
- 다중라운드 전문가 심의 → 의사결정문 합성
- 시뮬 심의 2단 수치 스파인 7석 고정 착석 + 카드 그라운딩 + 3단 구축 계획서(opt-in)

---

> M1~M3 은 토대(전달·에이전트화·안전), M4~M5 는 실제 업무 도구 장착·정상 가동, M6 은 다중 전문가 심의 단계.
