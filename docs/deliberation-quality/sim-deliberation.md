# 시뮬레이션 심의 — 설계

작성 2026-08-07 · 대상 `infra/pipeline/hwax-sim-deliberate.js`(신규), `HWAXAgentServer/deliberation.py`(2단 래퍼), 심의 페이지 모드
결정 사항 — 적용 범위는 **웹 메뉴 + MCP 둘 다**, 2단계 산출물은 **해석 계획서까지**(잡 제출 없음).

---

## 1. 무엇을 푸는가

기존 심의는 "원인이 무엇인가"에서 끝난다. 그런데 원인 가설이 서면 다음 질문은 항상 같다 — **"그래서 그걸 어떻게 계산으로 확인하고, 무엇을 설계 인자로 돌릴 것인가"**. 지금은 그 전환을 사람이 매번 손으로 한다.

S26U 액자형 수축이 정확한 예다. 메커니즘 심의로 산소 소광 가설(H1c)에 도달했고, 그 다음 반응-확산 PDE 모델·파라미터 확보 경로·식별성 전략을 사람이 별도로 설계했다. 이 두 번째 절반이 시뮬레이션 심의가 자동화할 구간이다.

---

## 2. 구조 — 2단, 좌석이 갈리고 일부가 넘어간다

```text
[1단 메커니즘 심의]              [좌석 전환]            [2단 해석 설계 심의]
현상 도메인 전문가                CAE 좌석 발굴          CAE 전문가 + 물리 유임자
주 도메인 + 반대 도메인    ──▶   + 물리 유임 1~2석  ──▶  해석 계획서
   ↓ 메커니즘 결론                                          ↓
   지배 물리·상태변수·                                   지배방정식·솔버·이산화·
   미지 파라미터·반증 조건                               파라미터 확보·검증·한계
```

### 2-1. 1단 — 메커니즘 심의

기존 심의를 그대로 쓴다(커버리지 게이트·조항 승계·앵커링 차단 전부 적용). 다만 **결정문 산출 항목이 다르다**. 2단에 넘길 것을 명시적으로 뽑아야 하기 때문이다.

- 지배 물리 과정 — 무엇이 무엇을 어떤 경로로 바꾸는가
- 상태변수와 그 공간·시간 스케일
- 지배방정식 후보(형태 수준)
- 미지 파라미터 목록
- 반증 관측 — 이 메커니즘이 틀렸다면 무엇이 보이는가

### 2-2. 좌석 전환 — 여기가 설계의 핵심

**CAE 전문가만 모으면 틀린 물리를 아름답게 계산한다.** 그래서 좌석 구성을 셋으로 나눈다.

| 구분 | 인원 | 근거 |
|---|---|---|
| **고정 CAE 좌석** | 2 (`xd-cae-modeling`, `xd-cae-post`) | 해석 방법론·검증은 현상과 무관하게 항상 필요하다 |
| **발굴 CAE 좌석** | 2~3 | 1단 결론의 물리 축으로 `recommend_agents` — 확산이면 전기화학·열, 충격이면 낙하·피로 |
| **물리 유임 좌석** | 1~2 | 1단 참여자 중 메커니즘을 가장 강하게 주장한 쪽. 해석이 물리에서 떠나는 것을 막는 감시자다 |

유임 좌석의 `origin` 은 `carry`, 나머지는 `new` 로 표시해 결정문이 좌석 구성을 기록한다.

### 2-3. 2단 — 해석 설계 심의

산출물은 **해석 계획서** 10개 항목이다.

1. 해석 목적 — 이 계산이 답할 질문 하나를 문장으로
2. 지배방정식과 물리 모델 (1단에서 승계, 수식 수준으로 확정)
3. 해석 종류·차원·기하 축약 — 3D full / 2D 평면·축대칭 / 1D, 그리고 축약의 정당화
4. 솔버·도구 선택과 근거 — **사내 보유 도구 우선**
5. 이산화 — 메시 전략, 시간 적분, 수치 기법과 안정성 조건
6. 경계·초기조건
7. **물성·파라미터 확보 경로와 식별성 판정**
8. 검증 계획 — 해석해·벤치마크·시험 대조
9. 계산 규모와 일정
10. **이 해석이 답할 수 없는 것**

7번과 10번을 반드시 강제한다. 이 둘이 "그럴듯한 계획서"와 "실제로 돌릴 수 있는 계획"을 가른다.

**7번 식별성 판정**이 특히 중요하다. 파라미터를 문헌/독립 측정/피팅으로 분류하고, 피팅 대상이 둘 이상이면 서로 곱으로 붙어 분리되지 않는지(퇴화) 판정해야 한다. S26U 반응-확산 모델에서 실제로 걸렸던 문제다 — 액자 폭 w(t) 단독 피팅으로는 확산계수와 억제 문턱이 분리되지 않아, 독립 관측 두 개(리셋 후 재성장 속도, 색별 폭 비율)를 추가해서야 퇴화가 풀렸다. 이 판정이 없으면 돌릴 수 없는 모델을 계획서로 받게 된다.

**10번 한계**는 심의가 만능 계산을 약속하지 못하게 막는 장치다.

## 3. 구현

### 3-1. MCP — `infra/pipeline/hwax-sim-deliberate.js` (신규)

기존 `hwax-deliberate` 를 **자식 워크플로로 두 번 호출**한다. 라운드 기계를 복제하지 않으므로 좌석 계약·조항 승계·앵커링 차단 개선이 자동으로 상속된다.

```text
phase('메커니즘')   → workflow('hwax-deliberate', {질문, personas: 도메인 좌석, chairTemplate:'mechanism'})
phase('좌석 전환')  → agent(CAE 좌석 발굴 — recommend_agents 로 물리 축 질의)
phase('해석 설계')  → workflow('hwax-deliberate', {질문: 해석 설계, personas: CAE+유임,
                                continueFrom:{summary: 1단 결정문, nonNegotiables}, chairTemplate:'sim-plan'})
```

`chairTemplate` 을 `hwax-deliberate` 에 새 인자로 추가한다 — 의장 산출 항목만 갈아끼우는 스위치다. 기본값은 현행 그대로라 회귀가 없다.

**선결 조건.** `.claude/workflows/hwax-deliberate.js` 가 `infra/pipeline/` 정본과 갈라져 있다(85줄 차이). 이름 호출이 옛 사본을 쓰므로 동기화가 먼저다.

### 3-2. 웹 — `deliberation.py` 2단 래퍼

`_deliberation_stream` 을 건드리지 않고 **두 번 돌리는 얇은 래퍼**를 얹는다. 라운드 루프를 리팩터링하면 회귀 위험이 크고, 래퍼는 기존 스트림 계약을 그대로 쓴다.

```text
run_sim_deliberation(app, question, groups, opts)
  ├ Phase A: _deliberation_stream(..., chair_template='mechanism')  → 결정문 가로채 보관
  ├ 좌석 전환: recommend_agents(물리 축) + 1단 유임 선별
  └ Phase B: _deliberation_stream(..., continue_summary=A결정문,
                                  continue_personas=CAE좌석, chair_template='sim-plan')
```

트리거는 `/시뮬심의` 로 하고, `is_deliberation` 과 같은 자리에서 분기한다.

### 3-3. 프론트 — 심의 페이지 모드

심의 페이지에 모드 선택(일반 심의 / 시뮬레이션 심의)을 두고, 시뮬레이션 심의면 전송 접두사를 `/시뮬심의` 로 바꾼다. 스테퍼는 2단을 반영해 단계 라벨을 늘린다.

---

## 4. 하지 않는 것

- **해석 잡 제출.** 계획서까지만 낸다. 입력 파일 생성이 필요하고 오작동 시 클러스터 자원을 먹는다. 실행 판단은 사람이 한다.
- **라운드 기계 복제.** MCP 는 자식 워크플로 호출, 웹은 스트림 2회 실행. 두 경로 모두 기존 기계를 그대로 쓴다.
- **CAE 좌석 전면 교체.** 물리 유임 1~2석은 반드시 남긴다.
- **`hwax-deliberate` 기본 동작 변경.** `chairTemplate` 미지정이면 현행과 완전 동일해야 한다.

---

## 5. 수용 기준

1. S26U 관측 5건 + COE 전제로 시뮬레이션 심의를 돌렸을 때, 2단 결정문이 **반응-확산 계열 지배방정식**과 **파라미터 식별성 판정**을 포함한다.
2. 2단 좌석에 CAE 도메인(`xd-`/`sim-`)과 1단 물리 유임자가 **함께** 있다(계측 하네스의 좌석 구성 지표로 확인).
3. 해석 계획서 10개 항목 중 7번(식별성)과 10번(한계)이 비어 있지 않다.
4. `chairTemplate` 미지정 심의의 결정문 형식이 기존과 동일하다(회귀 없음).
