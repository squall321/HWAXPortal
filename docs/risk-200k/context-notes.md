# 리스크 심사 20만 토큰 창 — 결정과 까닭

> 계획 [PLAN.md](PLAN.md) · 체크리스트 [checklist.md](checklist.md). 앞선 맥락은 재설계 [D-22](../risk-review-redesign/context-notes.md)(작은 창 장치를
> 만들지 않는다) · D-57(쟁점 패널 카드 절을 번갈아) · 메모리 'GLM 1M 창 · 잘라내지 않는다'(10-10).

**W-D1 목표는 '누락 0 · 멈춤 0' 이다 — 크기를 넘으면 나눠 여러 번 부른다(사용자, 2026-10-20).**
사용자 지시 그대로다 — "거절이 아니라 여러번 핑퐁을 치더라도 다 고려해야지". 그래서 재설계 D-22('창이 모자라면 잡을 멈추고 까닭을
말한다')를 뒤집는다. D-22 는 운영이 1M(GLM-5.2)이라는 전제(10-10)에서 '작은 창 박스는 설계 목표가 아니다' 로 내린 결정이었고,
그 전제가 20만으로 바뀌면 멈춤이 일상이 된다(W-D2 — 표본 전문가의 59%). 1M 박스의 동작은 바꾸지 않는다 — 1M 에서는 한계를 넘는
카드가 없어 조각 · 쪽이 생기지 않는다(표본 0장).

**W-D2 실측 — 20만에서 새는 곳은 '판정' 이 아니라 '멈춤' 과 '제목만' 이다(2026-10-20, dev).**
방법은 이렇다. dev AIDataHub 전문가 796명 가운데 무작위 30명(시드 20261020)과 두 명(xd-yield-ramp · material-twin-analyst)의
`/api/agents/{agent}/records` 를 읽어 엔진의 `normalize_card` · `assign_aliases`(= `render_card` 길이)로 펼쳤다. 한계는
`limits()` 와 `plan()` 의 식 그대로다(판정 한 장 자리 = `p_hard − verdict.fixed − unit_body_max`, 훑기 = `p_hard − sweep.fixed −
manifest_page_max`). 20만은 Claude 길 기본(창 200,000 · 출력 32,000)으로 셈했다.
- 카드는 짧은 메모가 아니라 문서다 — 한 장 중앙값이 전문가마다 2만~5만 자, 가장 긴 것 51.7만 자. 전문가 한 명의 전문 합 중앙값 244만 자.
- 한 장 자리(20만: 판정 131,560 · 훑기 126,012자)를 넘는 카드가 143장(2.5%), 그런 카드를 가진 전문가가 19/32명 — 지금은 그 전문가의
  잡이 `ctx_too_small` 로 선다. 1M 에서는 0장이다.
- 입력 결손 셀의 전문 몫 24,648자를 31/32명이 넘는다 — 지금은 넘는 카드가 제목으로만 실린다(`bg_dropped`).
- 판정 단계는 점검 카드 전부를 살아 있는 단위마다 대보므로(빠진 카드 재질의 포함) 카드를 빠뜨리지 않는다. 호출만 는다 —
  셀당 중앙값 2.6배(26 → 65), 최대 4.9배. 훑기는 4.5배(470 → 2,120).
표본은 dev 의 카드다. 운영 명단 전원의 분포는 W0 에서 cae00 에서 같은 방법으로 잰다(dev 리스크 원장에는 실제 실행이 없다).

**W-D3 '검토했다' 는 전문으로 실린 것만 센다.**
제목 · 목록 줄 · 다른 쪽의 제목 목록으로 실린 것은 커버리지에 넣지 않는다. 조각으로 실렸으면 그 카드의 모든 조각이 실려야 그 카드를
'전문 노출' 로 센다. 증명은 원장이다 — 잡을 닫을 때 '범위 안 살아 있는 셀에서 전문 노출 0인 카드 = 0' 을 불변식으로 본다.
어기면 조용히 끝내지 않고 목록을 단 partial 로 닫는다(무음 결함 규율 — '실패가 정상처럼 보인다' 를 만들지 않는다).

**W-D4 조각 경계는 결정적이고, 절 번호는 원래 것을 쓴다.**
같은 카드면 같은 조각이어야 다시 돌기(셀 지문)와 vLLM 접두 캐시가 산다. 경계는 절 → 문단 → 문장 차례이고, 한도 안에서 가장 큰 덩이를
먼저 쓴다. 인용 대조는 원래 절 번호(`§3`)와 원문 위치로 하므로 조각 때문에 인용이 틀리지 않는다. 조각에는 카드 틀(머리 · 제목 ·
전체 목차 · 조각 위치)을 실어 모델이 카드 전체의 모양을 안다.

**W-D5 나눠 부른 결과는 코드로 합치고, 갈릴 때만 한 번 더 부른다.**
합치기 규칙은 결정적이다 — 해당은 '어느 조각 · 쪽이든', 판정은 가장 무거운 것, 인용은 다 모은다. 같은 카드의 조각끼리 판정이
갈리면(한쪽 FAIL, 다른 쪽이 반박 근거) 두 조각에서 인용된 절만 모아 그 카드 하나를 다시 판정한다. 배경 · 입력 결손의 쪽이 둘 이상이면
셀마다 합치기 호출을 한 번 더 부르되, 합치기는 새 지적을 만들지 못하게 한다(출력 인용이 입력 지적의 인용 안이어야 받는다).

**W-D6 열린 물음은 사용자 몫이다(PLAN 4절).** 20만 모델의 길(GLM 자리 · 사내 모델 · Claude 길 — 비용과 시간이 갈린다), G3 기준값,
패널 좌석의 다시 읽기 도구(E2), 카드 수천 장 전문가의 처리, 1M 박스에도 켤지.
