# MCP 앱 켜고 끄기 — 판단 기록

## 2026-09-29

**D-1 등록 분리(A)보다 포털 스위치(B)가 먼저다.** 클라이언트에서 앱별 서버를 끄는 것만으로는 "검색에서 빠지게" 가
안 된다 — 게이트웨이 `search_tools`·`invoke_tool` 이 권한 있는 모든 앱을 찾는다. 앱별 등록을 기본값으로 하면 서버
항목·PAT 평문 사본·(자체서명이면) npx mcp-remote 프로세스가 앱 수만큼 늘고, 등록이 토큰 발급 시점에 고정돼 새 앱은
.bat 재실행 전까지 안 보이며, 도구 이름이 `mcp__hwax-<앱>__X` 로 바뀌어 기존 권한 규칙(리포 settings 의
mcp__hwax__ 47개)이 깨진다. Claude Code `/mcp` 끄기는 프로젝트(폴더)마다라 포털 스위치(전 클라이언트 전역)보다 좁다.
`/mcp/<app>` 엔드포인트 자체는 가능함을 탐침으로 확인했다(같은 FastMCP·세션매니저에 Route 추가, 세션은
mcp-session-id 로만 찾으므로 앱 범위는 요청 경로에서 매번 계산). 사용자 결정: 1단계 포털 스위치, 앱별 등록은
2단계 선택 기능.

**D-2 개인 MCP 클라이언트만.** 웹 챗은 챗 PAT(`pat_name=chat-session`)로 같은 게이트웨이를 타는데, 에이전트 서버는
tools/list 에서 이름으로 찾아 **코드로** 부르는 도구가 있다(/보고서의 create_report_draft, 띵킹의 recommend_agents).
챗 PAT 까지 거르면 그 기능이 깨진다. 심의는 조직 차원 결론이라 개인 관심사로 근거가 줄면 안 된다(GW_TOKEN 경로라
자연히 면제). 절차 PAT(purpose=procedure)는 tools/list 로 카탈로그를 만들므로 면제. 사용자 결정.

**D-3 숨김만(호출 차단 없음).** 끄기는 선호다. 호출을 막으면 use_experts 가 안에서 부르는 get_agent_session
(ai-data-hub)이 막히고 절차 면제 규칙을 따로 만들어야 한다. 사용자 결정.

**D-4 게이트웨이 앱 단위.** 모델이 보는 단위(search_tools 의 app, list_tool_apps)와 같다. 포털 플랫폼 단위는
smarttwin 하나가 백엔드 셋을 묶고, access.yaml 에 없는 heax-* 앱은 표에 안 나온다. 사용자 결정.

**D-5 저장 칸은 권한과 따로.** user_store 의 규칙("본인이 바꿀 수 있는 값이 권한이 되면 스스로 올릴 수 있다")에
비춰, 끄기는 도구를 **덜 보게만** 하므로 본인이 바꿔도 된다. 다만 `grants` 와 섞지 않고 새 칸 `hub_muted_apps` 에
둔다. 게이트웨이 쪽도 합성 그룹(x-hwax-groups)에 싣지 않고 전용 헤더를 쓴다 — 그룹에 섞으면 응답 캐시 키가 사람마다
쪼개지고 심의 백엔드로 전달되며 권한 의미와 섞인다.

**D-6 끔 ≠ 권한 없음.** list_tool_apps 는 `denied_apps` 와 별개인 `muted_apps` 칸을 낸다. 같은 칸을 쓰면 모델이
사용자에게 "권한을 요청하라" 고 안내한다(허브 지침 9번의 사유별 안내).

**D-7 검토 1차(2026-09-29) — 확인 5건, 전부 반영.**
- (중간) **D-2 의 전제 정정.** "심의는 GW_TOKEN 경로라 자연히 면제" 는 웹 심의·게이트웨이 deliberate_* 에만 맞다. Claude Code 에서
  돌리는 심의 워크플로(infra/pipeline/hwax-deliberate.js)는 리포 .mcp.json 의 **개인 PAT** 로 돈다 — 끈 앱이 좌석의 도구 목록·
  search_tools 에서 빠지고, RA 를 끈 사람의 보고서 저장이 "도구가 사용 가능하면…" 지시 때문에 'RA 미가용' 으로 끝났다.
  이 경로를 따로 가를 표지가 없다(헤더는 .mcp.json 에 고정). 그래서 개인 클라이언트로 보고 끄기를 적용하되, 파이프라인이 **꼭
  필요한 도구**(보고서 저장·쪽수 조회·이어붙이기, RA 조회 힌트, 카드 그라운딩)는 "목록에 없으면 invoke_tool 로 이름을 주어
  부르라" 는 문장(BY_NAME)을 붙였다(숨김만이라 이름으로는 된다). 탐색 검색은 사용자의 끄기를 따른다. 화면 문구는 '웹 심의' 로 좁혔다.
- (낮음) 챗 PAT 면제를 `pat_name` 만으로 판정했다 — 개인 토큰 이름을 chat-session 으로 지으면 피해 갔다. 서버가 정하는 `jti`
  의 'chat-' 머리도 본다. 포털 값과 게이트웨이 값을 대조하는 시험을 게이트웨이에 뒀다.
- (중간→낮음) 화면이 목록 전체를 보내 두 탭이 서로의 선택을 되돌렸다 → `PUT /auth/access/apps/{key}`(앱 하나), 저장소가 잠금
  안에서 읽고-고쳐-쓴다. 켜기는 게이트웨이에 없는 앱도 받는다(빠진 앱의 끈 기록 때문에 화면이 계속 실패하지 않게). 실패하면 다시 읽는다.
- (낮음) 스위치 이름이 '보임/꺼짐' 뿐이었다 → aria-label 에 앱 이름. (낮음) 저장 중 disabled 로 포커스가 사라졌다 → aria-disabled.
