> 받는 분 — FMEA Agent 개발 · 운영 담당. 보내는 쪽 — HWAX 포털(MCP 게이트웨이를 맡은 쪽). 건네는 사람 — 사용자.
> 함께 건넬 것 — 공통 계약 [../contract.md](../contract.md). 고친 날 2026-11-27(처음). 숫자는 운영 박스 기록에서 옮겼고 날짜를 붙였다.

## 0. 무엇 · 왜

HWAX 포털의 MCP 게이트웨이에는 운영 박스 기준 백엔드 35 · 도구 1,984개가 모이고(11-26), 그 가운데 약 1,200개가 사내 앱 도구다. 웹 챗 · 심의 좌석 · 개인 Claude 는
도구를 이름 · 설명 · 인자 스키마만 보고 고르고 부른다. 그 셋이 산문 · 빈칸이면 2,000개 속에서 잘못 고르고, 인자를 지어내고, 읽기 도구를 쓰기로 막는다.

FMEA Agent 는 사람이 자기 토큰을 포털에 등록해 붙는 외부 연결이다(10-21 결정). 그런데 목록부터 토큰이 있어야 해서 게이트웨이가 도구를 미리 알 수 없고, 표지가 없어
자동 실행에서 읽기 도구를 열 수 없다. 이 글은 그 둘과 상시 운영을 먼저 적는다.

## 3. 프로토콜 — stateless · 두 세대

- **1단계(먼저)** — 서버가 세션을 쥐지 않는다(P1). Python SDK 1.x(FastMCP)면 생성자에 `stateless_http=True` 한 줄, TypeScript SDK 면 streamable HTTP 전송의 세션 id
  생성기를 비운다. 서버 발 알림 · sampling · elicitation 을 쓰고 있으면 알려 주세요.
- **2단계** — Python SDK 2.x(`mcp>=2.3`, Python 3.11 이상)로 2026-07-28 새 세대와 옛 세대를 같은 자리에서(P2). 새 세대에는 initialize 가 없으므로, 토큰 검사를
  initialize 에 걸어 두었다면 그 자리를 도구 호출로 옮겨야 한다(위 2절 1과 같은 뜻). 모델이 읽어야 할 오류는 `ToolError` 로(P3).
- 게이트웨이는 옛 세대 앱도 계속 부른다 — 2단계를 서두르지 않아도 끊기는 것은 없다.

## 4. 로드맵 — R1 · R2 · R3

- **R1 이벤트** — 새 사례 · 규격 바뀜이 있으면 「바뀐 것 목록」 읽기 도구(커서 · 시각 · 종류 · id)로. 바뀜이 드물면 「안 함(까닭)」 으로 답해도 된다.
- **R2 길 안내** — 대표 업무 둘 ~ 다섯(예 — 부품 · 고장모드로 사례 찾기 → 규격 대조)을 「목적 · 차례 · 입구 도구 · 확인할 쓰기」 로 보내 주세요.
- **R3 앱 입구** — 처음 부를 때 먼저 부를 도구 하나(서버 설정 점검 · 안내 류)를 정해 알려 주세요.
