## 0. 무엇 · 왜

HWAX 포털의 MCP 게이트웨이에는 운영 박스 기준 백엔드 35 · 도구 1,984개가 모이고(11-26), 그 가운데 약 1,200개가 사내 앱 도구다. 웹 챗 · 심의 좌석 · 개인 Claude 는
도구를 이름 · 설명 · 인자 스키마만 보고 고르고 부른다. 그 셋이 산문 · 빈칸이면 2,000개 속에서 잘못 고르고, 인자를 지어내고, 읽기 도구를 쓰기로 막는다.

SimEngBay 는 해석 엔지니어링 저장소다. HWAX 쪽에 알려진 것이 가장 적은 앱이라, 이 글은 공통 계약 전체를 그대로 청하고 운영 박스 품질 카드로 차례를 정한다.

## 3. 프로토콜 — stateless · 두 세대

- **1단계(먼저)** — 서버가 세션을 쥐지 않는다(P1). Python SDK 1.x(FastMCP)면 생성자에 `stateless_http=True` 한 줄, TypeScript SDK 면 streamable HTTP 전송의 세션 id
  생성기를 비운다. 서버 발 알림 · sampling · elicitation 을 쓰고 있으면 알려 주세요(1단계에서 버려진다).
- **2단계** — Python SDK 2.x(`mcp>=2.3`, Python 3.11 이상)로 2026-07-28 새 세대와 옛 세대를 같은 자리에서(P2). 2.x 는 인자 설명을 `Field(description=)` 에서만 읽는다.
  모델이 읽어야 할 오류는 `ToolError` 로(P3).
- 게이트웨이는 옛 세대 앱도 계속 부른다 — 2단계를 서두르지 않아도 끊기는 것은 없다.

## 4. 로드맵 — R1 · R2 · R3

- **R1 이벤트** — 새 해석 항목 등록을 「바뀐 것 목록」 읽기 도구(커서 · 시각 · 종류 · id)로. 이름은 `<앱>.<대상>.<일>` 꼴(예 `simengbay.entry.created` — 이름은 앱이 정한다).
- **R2 길 안내** — 대표 업무 둘 ~ 다섯을 「목적 · 차례 · 입구 도구 · 확인할 쓰기」 로.
- **R3 앱 입구** — 처음 부를 때 먼저 부를 도구 하나.
