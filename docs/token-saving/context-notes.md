지우지도 않는다. CLAUDE.md 는 표지 두 줄(`<!-- hwax-offload:begin/end -->`) 사이만 쓰고 걷는다 — 끝 표지가 없으면 건드리지 않고, 엄격 UTF-8 로 못 읽으면(5.1 이
