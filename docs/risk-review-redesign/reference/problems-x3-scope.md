## 2. 문제 (찾는 대로 덧붙임)

### X3-01 [blocker] 실측이 걸음이 아니다 — 가장 이른 실측도 33걸음 뒤, 일정을 고쳐 적는 자리는 48걸음 뒤다

- 근거. WP3b 3.14.1 "벽시계는 호출 시간에 비례하는데 그 값이 없다 … 호출 1회 5분 … 전부 추정이다", 같은 절의 표(B=8·r=1.0 이면 8,960회·동시 4 에서 7.1일·동시 2 에서 14일). WP3a 9절 첫 줄 "GLM 의 실제 자/토큰 비. 예산은 엔진의 최악값 1.05 로 잡았다. 카드 표본의 token_estimate 는 2.9 쪽을 가리킨다".
