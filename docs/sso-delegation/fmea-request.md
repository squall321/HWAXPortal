# FMEA Agent — HWAX 포털에서 사람별로 붙기 위한 요청

> 받는 분: FMEA Agent 개발 · 운영 담당 · 보내는 쪽: HWAX 포털 운영 · 2026-10-20
> 포털 사용자의 Claude(Claude Code · Claude Desktop)와 포털 챗이 FMEA Agent 를 **그 사람 이름으로** 쓰게 하려 합니다.
> 아래 (가) · (나) 중 하나를 갖춰 주시고, 맨 아래 질문에 답해 주세요.

## 무엇을 하려는가

HWAX 포털의 MCP 게이트웨이는 사람마다 Claude 와 포털 챗을 사내 서비스의 MCP 도구에 연결합니다. 호출은 늘 **그 사람의 자격**으로
나갑니다 — 공용 계정으로 대신 부르지 않습니다(그러면 남의 자료가 보이고, 쓴 기록이 한 사람에게 몰립니다). Report Archive · TestScope ·
MatNexus 가 이 방식으로 붙어 있거나 붙는 중입니다.

## 갖춰 주실 것 — 둘 중 하나

### (가) 표준 위임 창구 — 권장

사람이 토큰을 복사할 일이 없습니다. 게이트웨이가 공유 비밀로 "이 사람" 을 알리면 그 사람 이름의 개인 토큰을 내주는 창구입니다.
TestScope · MatNexus 가 같은 계약으로 구현해 두었습니다(두 리포의 `backend/app/modules/auth/gateway_token.py` — 볼 수 있으시면 그대로 참고하셔도 됩니다).

| | 내용 |
|---|---|
| `POST /api/auth/sso` | 그 사람의 토큰 발급 |
| `POST /api/auth/sso/verify` | 비밀만 확인 — 204 / 401. 아무것도 만들지 않습니다(설정 점검용) |
| `POST /api/auth/sso/revoke` | 그 사람 · 그 client 의 위임 토큰 폐기 — 200 `{"revoked": n}`, 폐기할 것이 없어도 200 |
| 요청 헤더 | `X-Heax-Gateway-Secret: <공유 비밀>` · `X-Heax-User-Email: <포털이 확인한 이메일>` · `X-Heax-User-Name: <표시 이름, 퍼센트 인코딩 — 선택>` · `X-Heax-Client: gateway` |
| 발급 응답 200 | JSON 안 어딘가의 `access_token` 과, 같은 객체의 `expires_in`(초). 예 `{"success": true, "data": {"access_token": "<토큰>", "token_type": "bearer", "expires_in": 172800}}`. 게이트웨이는 `access_token` 을 깊이 찾고, `expires_in` 보다 일찍 다시 받습니다(최대 12시간 캐시, 401 을 받으면 한 번 다시 받습니다) |
| 상태 코드 | 비밀이 비어 창구가 꺼짐 **404** · 비밀 불일치 **401** · 그 사람을 들일 수 없음(계정 없음 · 승인 대기 · 정지) **403**. 404 는 '창구 꺼짐' 에만 써 주세요 — 사람 하나의 거절을 404 로 내면 게이트웨이가 창구 전체가 꺼진 줄 압니다 |
| 지켜 주실 것 | 비밀은 상수 시간으로 비교 · 이메일 형식이 아니면 401 · 같은 client 의 직전 토큰은 폐기하고 새로 발급(쌓이지 않게) · 발급을 감사에 남김 · (선택) 허용 IP(`X-Forwarded-For` 는 믿지 않음) |
| 정하실 것 | 계정이 없을 때 만들지 않을지(TestScope · MatNexus 는 만들지 않고 403) · 위임 토큰을 읽기 전용으로 할지(두 곳 다 읽기 전용) · 토큰 수명(두 곳 다 2일) |

### (나) 최소 — 개인 토큰 + 본인 확인

위임이 어렵다면 사람이 FMEA Agent 화면에서 개인 토큰을 발급해 포털 '개인 토큰 › 외부 연결' 에 붙여 넣는 방식입니다(TestScope 가 처음 이렇게
붙었습니다). 필요한 것은 둘입니다.

- 사람이 화면에서 발급하는 개인 토큰 — 알아보기 쉬운 접두사가 있으면 좋습니다(예 `tsc_pat_`).
- `GET /api/auth/me`(헤더 `Authorization: Bearer <토큰>`) → 200 JSON 에 `email`. 포털은 이 이메일이 포털 계정과 같을 때만 등록합니다(남의 토큰 등록 방지).

이 경우 포털 · 게이트웨이 쪽 코드를 저희가 더 써야 해서 (가)보다 늦어집니다.

## MCP 서버

- Streamable HTTP 엔드포인트(예 `http://<주소>:<포트>/mcp`).
- 받은 `Authorization` 헤더를 그대로 백엔드로 넘겨 거기서 판정해 주세요. MCP 서버에 만능 토큰을 두면 모든 사용자가 같은 권한이 됩니다.
- Host 허용목록을 쓰신다면 게이트웨이가 부르는 주소를 **포트까지 그대로** 넣어 주세요(TestScope · MatNexus 는 글자가 다르면 421 로 거절합니다).
- 게이트웨이 서버에서 들어오는 TCP 를 방화벽에서 열어 주세요 — 위임 창구가 있는 포트와 MCP 포트 둘 다입니다.
