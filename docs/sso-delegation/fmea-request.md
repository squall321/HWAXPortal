# FMEA Agent — HWAX 포털에서 사람별로 붙기 위한 요청

> 받는 분: FMEA Agent 개발 · 운영 담당 · 보내는 쪽: HWAX 포털 운영 · 2026-10-20(10-21 개정 — 개인 토큰 방식으로 정했습니다)
> 포털 사용자의 Claude(Claude Code · Claude Desktop)와 포털 챗이 FMEA Agent 를 **그 사람의 토큰으로** 쓰게 하려 합니다.
> 저희 쪽 준비는 끝났습니다. 아래 '청할 것' 다섯에 답해 주시면 됩니다.

## 무엇을 하려는가

HWAX 포털의 MCP 게이트웨이는 사람마다 Claude 와 포털 챗을 사내 서비스의 MCP 도구에 연결합니다. 호출은 늘 **그 사람의 자격**으로
나갑니다 — 공용 계정으로 대신 부르지 않습니다(그러면 남의 자료가 보이고, 쓴 기록이 한 사람에게 몰립니다).

FMEA Agent 는 **개인 토큰 방식**으로 붙습니다(10-20 판의 (나)).

- 사람이 FMEA Agent 화면의 토큰 메뉴(`/tokens`)에서 개인 토큰(`fmea_…`)을 발급해 포털 '개인 토큰 › 외부 연결' 에 붙여 넣습니다.
  앞에 `Bearer` 가 붙어 있어도 됩니다.
- 게이트웨이는 그 사람의 호출을 그 토큰으로만 보냅니다. 토큰을 등록하지 않은 사람의 호출은 거절하고 등록을 안내합니다.
- 등록할 때 그 토큰으로 MCP `initialize` 를 한 번 보내 200 인지만 봅니다(만료 · 오타 거르기). 토큰의 주인은 확인하지 않습니다 — 포털은 새
  플랫폼의 토큰 주인을 확인하지 않기로 했습니다(10-21). 그래서 10-20 판에서 청했던 **본인 확인 API(`/api/auth/me`)는 청하지 않습니다.**
- 10-20 판의 (가) 표준 위임 창구도 이번에는 쓰지 않습니다.

## 청할 것

1. **토큰 없이 `initialize` · `tools/list` 를 열어 줄 수 있습니까?** 지금은 `initialize` 부터 401 `unauthenticated` 입니다. 그래서 게이트웨이가
   사람 없이 도구 목록을 받으려면 목록 전용 FMEA 계정의 토큰을 따로 등록해 두어야 합니다(목록에만 쓰고 호출에는 쓰지 않습니다). 열어 주시면 그
   계정이 필요 없어집니다. TestScope · MatNexus 는 목록을 열어 두고 데이터를 내는 호출만 토큰을 요구합니다.
2. 토큰 수명과 폐기 방법, 읽기 전용 토큰이 있는지 알려 주십시오.
3. 도구에 **`readOnlyHint`** 를 달아 주십시오. 지금 23개 모두 없어서, 읽기 전용 자격으로 붙은 Claude 에서는 전부 쓰기로 보고 막힙니다.
   쓰는 도구(`add_material_baseline_overlay_tool` · `add_spec_overlay_tool`)와 읽는 도구를 가를 수 있게 하려는 것입니다.
4. Host 허용목록을 쓰신다면 게이트웨이가 부르는 주소(`<FMEA_호스트>:5190`)를 **포트까지 그대로** 넣어 주십시오. 게이트웨이 서버에서 들어오는
   TCP(5190)는 방화벽에서 열어 두어야 합니다.
5. 서버가 개인 PC 에서 도는 것으로 보입니다. 그 PC 가 꺼지면 포털 사용자에게서 FMEA 도구가 사라집니다. **상시 운영 계획**과 연락 · 운영 담당을
   알려 주십시오.

## MCP 서버에 지켜 주실 것

- 받은 `Authorization` 헤더를 그대로 백엔드로 넘겨 거기서 판정해 주십시오. MCP 서버에 만능 토큰을 두면 모든 사용자가 같은 권한이 됩니다.
- 쓰기 도구는 토큰 주인 명의로 기록됩니다. 포털 카드에 그 사실을 적어 둡니다.

## 저희가 하는 일

- 포털 박스 권한표의 FMEA Agent 항목에 연결 선언(`connect:`) 한 블록 — MCP 주소 · 토큰 접두(`fmea_`) · 발급 화면 주소 · 카드 안내 문구.
  코드 · 빌드 · 재기동이 없습니다.
- 1번 답을 받기 전까지는 목록 전용 FMEA 계정(FMEA `/signup` 으로 만든 로컬 계정)의 토큰을 포털의 목록 계정이 등록해 게이트웨이가 도구 목록만
  받습니다. 열어 주시면 설정 한 줄(`list_auth: open`)로 바꿉니다.
- 3번 답을 받기 전까지는 저희 쪽에서 읽기 도구 이름을 목록(`read_tools`)으로 적어 둘 수 있습니다. 그쪽이 `readOnlyHint` 를 달면 그것을
  따릅니다(그쪽이 `readOnlyHint=False` 로 적은 도구는 쓰기로 봅니다).
