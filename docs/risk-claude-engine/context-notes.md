# 리스크 심사 Claude 길 — 결정과 까닭

**X-D1 사용자 결정(2026-10-15).** "일단 현행 계획대로 완료해주고 완전 클로드 버전으로도 할 수 있게끔만 해두고 그거는 테스트는 하지 말고 유저가 원하면 할 수 있게끔만 하자." — M3 는 GLM 으로 끝내고, Claude 길은 지어 두되 기본 꺼짐이다. '테스트는 하지 말고' 는 실제 Claude 로 심사를 돌리는 시험(사용량)을 하지 않는다는 뜻으로 읽었다 — 가짜 응답자로 배선이 깨지지 않았는지 보는 코드 시험은 넣는다(전역 지침 8 '테스트 후 완료').

**X-D2 사용량 어림(10-15, 실측 아님 — ±40%).** M3 전원 한 번은 호출 약 17,000(거르기 꺼짐)·10,000(켬), 입력 약 2.4억·1.5억 토큰, 출력 약 3,500만·2,200만 토큰이다. 바탕 — 카드 전부 평균 57,072자·카드당 약 1,900자·점검 카드 12.9장(8장씩 셀당 2번)·글자/토큰 2·단위 본문 3,000자(M0-c 미실측이 가장 큰 불확실). Claude Code 서브에이전트로 돌리면 호출마다 기본 문맥이 붙어 묶어 처리하지 않으면 두 배 가까이 된다. 그래서 전원 전부를 Claude 로 돌리는 것은 구독 한도로는 현실적이지 않다고 사용자에게 말했고, 나눠 쓰기(카드 대조 GLM · 쟁점 패널·종합만 Claude, 약 3,000만 토큰)와 대표 9명 비교 실행(600만~800만 토큰)을 권했다.

**X-D3 모양 — 앱이 아니라 엔진의 LLM 자리에 꽂는다.** 앱이 Claude 에게 직접 과제를 주면 엔진의 프롬프트·파서·보충 되묻기를 둘로 갈라 지녀야 한다(엔진과 앱의 정체성 규칙이 어긋나 D-44·D-46 의 결함이 났던 것과 같은 길). 엔진의 `delib_llm` 자리에 외부 응답자를 꽂으면 계약·검사·원장이 하나로 남는다. 쟁점 패널은 외부 응답자가 엔진의 도구를 실행할 수 없어 evidence_only 로 돈다.

**X-D4 X-1 을 지으며 정한 것(2026-10-15, 가지 `external-llm`).** 엔진에는 `tool_mode` 가 없다 — evidence_only 는 좌석의 자유 조회(`free_tools`)를 끄는 것이다. 외부 심의는 그 창(`EXTERNAL_LLM_CTX_TOKENS`)으로 근거 예산을 다시 잰다(1M 창 기준으로 지은 프롬프트가 Claude 로 가지 않게 — /health 의 `evid_budget`). 부재 판정은 '그 주인이 조용한 시간' 으로 잰다 — 주인이 과제를 집고 있는 동안은 대기 과제가 늙지 않는다(좌석 20개를 한 워커가 차례로 답하는 동안 '부재' 가 되지 않게). GLM 계약 디렉터리는 그대로 두고 외부 계약은 따로 둔다(리스크 앱이 GLM 계약을 바이트째 복사해 포털이 재생한다).

**X-D5 반대 검토 1라운드(2026-10-15, HIGH 1 · MEDIUM 2 · LOW 8 · 가설 2).** ① 요청이 다시 줄을 선 뒤 새로 집히면 앞 집기의 늦은 제출이 새 집기의 버퍼에 섞였다(두 답이 이어 붙은 '잘 생긴' 답) — 집기마다 `lease` 를 주고 읽기·제출이 그것을 요구한다. ② 퍼센트 풀기를 날 이메일에도 걸어 `ev%41l@…` 가 다른 사람의 과제를 받았다 — 게이트웨이 머리에서 온 신원만 푼다. ③ 사람 속도로 답하는 워커를 기다리는 외부 호출이 GLM 관문 자리를 쥐어 다른 사람의 GLM 카드 대조가 막혔다 — 외부 호출은 GLM 자리를 쓰지 않고 주인마다 상한(`EXTERNAL_LLM_MAX_INFLIGHT`)을 두되, 비우기 중에는 거절하고 비우기가 기다리는 활동 수에 든다(재기동은 메모리의 줄을 잃는다). ④ **반출 동의를 엔진도 본다** — 외부로 내용을 보내는 요청(카드 대조 run · 외부 심의 · MCP `advanced.llm`)은 `consent_external: true` 가 없으면 과제를 만들기 전에 `external_consent_required` 로 거절한다(앱이 동의를 받고 누가 했는지 적는다 — 엔진의 검사는 그 겹 위의 한 겹이다). ⑤ 이 박스의 GLM 챗·심의 에이전트는 과제 도구 셋을 묶지 않는다(지식카드에 숨은 지시로 챗이 사용자의 과제를 집거나 답하지 않게). ⑥ 작은 것 — 근거 예산 캐시를 창별 한 값으로, 부재 빠른 실패는 WAIT_S 뒤 풀림, 오프셋은 '유니코드 코드 포인트' 라고 적고 머리에 `max_chars`, 외부 길의 잘림 오류는 `EXTERNAL_LLM_MAX_TOKENS` 를 손잡이로, GLM 이어하기가 강제된 `free_tools:0` 을 물려받지 않게, 켠 박스에서 값이 틀리거나 시간 사슬이 깨지면 기능을 끈 채 기동 오류(더 큰 기본값으로 조용히 가지 않는다), 오래 쉰 주인 항목 정리.
