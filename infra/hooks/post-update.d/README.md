# 박스 훅 — update-all 끝에서 도는 박스 파일

update-all 은 모든 배포와 끝맺음(비우기 · 새 심의 멈춤 · 상태판 경보 풀기)이 끝난 뒤, 끝 요약 바로 앞에서 이 폴더의 `*.local.sh` 를 이름
차례로 돌린다. 차례는 로캘과 무관한 C 차례이니 `10-` · `50-` 처럼 앞에 숫자를 붙인다. 정본 설명은 [`../../../docs/core-link/`](../../../docs/core-link/)
(SRC-12 · CK-6 · CK-10)에 있다.

- **박스 파일이다.** `*.local.sh` 는 `.gitignore` 에 있어 git 이 모르고, update-all 의 `git stash -u` 가 치우지 않는다.
  - 이 무시 규칙이 든 판을 받은 뒤에 훅을 만든다.
  - 이름이 `.local.sh` 로 끝나지 않으면 돌지 않고, 다음 update-all 앞머리의 stash 가 치운다. 되찾기는
    `git show 'stash@{0}^3:infra/hooks/post-update.d/<이름>' > <이름>` 이다.
  - 점으로 시작하는 이름은 돌지 않는다.
- **어떻게 도나.**
  - 훅은 `bash <훅>` 으로 돈다. 실행 비트는 필요 없다.
  - 작업 폴더는 포털 리포 루트이고, 표준 입력은 비어 있다.
  - 환경에 `HWAX_UPDATE_FAIL` 이 실린다. 이 실행이 이미 실패를 셌으면 1 이다.
  - update-all 의 조율 변수(장부 · 심의 멈춤 표지 · 재실행 표지 · `--with`)는 넘어오지 않는다. 훅에서 `update-sites.sh` 같은 것을 불러도
    update-all 의 일부로 굴지 않는다.
  - 훅은 제 세션 · 프로세스 묶음에서 돈다. 훅 안의 `kill 0` 은 그 훅에만 닿는다.
  - 앞 훅이 실패해도 다음 훅은 돈다.
- **실패.** 훅의 종료코드는 update-all 의 종료코드에 들지 않는다. 끝 요약에 줄 하나로 따로 나온다 — `박스 훅 N개 중 M개 실패 — 이름(rc)`.
  모두 끝났으면 `모두 끝났다` 다.
- **상한.** 훅마다 `HWAX_HOOK_TIMEOUT_S`(기본 3600초)다.
  - 넘기면 그 훅의 프로세스 묶음을 통째로 끝내고(TERM, 삼키면 10초 뒤 KILL) `상한 N초` 로 센다.
  - 스스로 떨어져 나간 데몬(`setsid`)은 남는다.
  - 훅은 오래 걸리는 일을 기다리지 말고 걸어 두고(잡 넣기) 끝내는 편이 낫다.
- **멈추기.** 훅이 도는 동안 Ctrl-C 나 `kill <update-all>` 을 하면 그 훅을 끊고 남은 훅을 건너뛴 뒤 끝 요약을 그대로 낸다. 종료코드는 배포
  결과를 따른다.
- **일이 있을 때 건너뛰기.** `./infra/scripts/update-all.sh --hooks-when-idle` 이면 다음 가운데 하나라도 있으면 훅을 건너뛴다(○).
  - 도는 · 줄 선 심의, 리스크 카드 대조(에이전트 서버 `/health`)
  - DynaForge 로컬 작업(30초 안에 못 세면 '모름')
  - StepForge(pending · running) · DocForge(queued · running) 작업

  셀 수 없는 칸이 있어도 건너뛴다(모름은 '없음' 이 아니다). 인자는 글자 그대로 `--hooks-when-idle` 이어야 한다. update-all 은 모르는 인자를
  말없이 넘긴다.
- **비밀.** 훅에 토큰을 적어야 하면 파일 권한을 600 으로 둔다. 박스 작업용 서비스 토큰은 포털 토큰 화면의 '서비스 토큰'(관리자 — core-link
  SRC-13)에서 받는다.
